# Project Context

This project is a short practical note/blog-post-style document about lessons learned from research assistant work.

The goal is to preserve rough material and gradually shape it into a readable few-page piece with practical recommendations. The draft is intentionally not polished yet, so edits should usually focus on structure, clarity of examples, and preserving useful material rather than rewriting the voice.

Main working file:

- `ra_lessons.Rmd`

Rendered output is generated locally and does not need to be tracked while the draft is changing often.

General editing preference:

- Preserve the author's wording unless explicitly asked to edit.
- Reorganising sections is okay when it helps the structure.
- Add examples, checks, or suggestions where useful, but avoid over-specifying the final order too early.
- Keep the document practical and concise rather than turning it into a full methods guide.
