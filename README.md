# Data Work for Economics Research

These are notes from working with data for economics research projects, mainly in R and often with spatial data.

[`ra_lessons.Rmd`](ra_lessons.Rmd) is the source for the shareable [`ra_lessons.html`](ra_lessons.html).

[`dataset-cleaning-review/`](dataset-cleaning-review/) is a skill for reviewing research data construction, including joins, identifiers, missingness, aggregation, spatial work, and validation.
